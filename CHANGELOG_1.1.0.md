# KoalaTV 1.1.0

- Se incorpora recuperación del último canal visto al iniciar la aplicación.
- La identidad del canal se conserva por URL para tolerar cambios de numeración al actualizar listas.
- Si el canal guardado ya no está disponible, se usa el canal predeterminado.
- Se conserva la arquitectura y las funciones existentes de KoalaTV.
- Se documenta la relación con OwnTV y el límite de licencia GPL-3.0.
